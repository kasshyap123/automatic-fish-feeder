# Automatic Fish Feeder

An Arduino-based automatic fish feeder developed as a team project at RV University.

The project combines Arduino programming and mechanical design using Autodesk Fusion 360.

## Achievement

Our team won **first place in a college competition** during our second semester.

## My Contribution

I contributed across the project’s development, including:
- Arduino programming.
- CAD design using Autodesk Fusion 360.
- Collaboration with teammates on the overall project.

## Mechanical Design

The project’s Fusion 360 design files cover:
- Enclosure
- Feeder hopper
- Main body
- Screw conveyor redesign

## Tools Used

- Arduino
- Autodesk Fusion 360
